Using CSS Variables

All brand colors are available as CSS custom properties (variables) that can be used throughout your stylesheets:

/* Primary Colors */ var(--symmetri-red) var(--symmetri-magenta) var(--symmetri-orange) var(--symmetri-yellow) var(--symmetri-yellow-warm) /* Neutral Colors */ var(--symmetri-black) var(--symmetri-dark-gray) var(--symmetri-medium-gray) var(--symmetri-light-gray) var(--symmetri-white) /* Gradients */ var(--symmetri-gradient-primary) var(--symmetri-gradient-warm) var(--symmetri-gradient-bold)

Example Usage:

.my-component { background-color: var(--symmetri-red); color: var(--symmetri-white); border: 2px solid var(--symmetri-yellow); } .my-gradient-bg { background: var(--symmetri-gradient-primary); }
