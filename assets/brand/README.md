# Symmetri Brand Assets

This directory contains all brand assets for the Symmetri brand identity.

## Directory Structure

```
brand/
├── README.md (this file)
├── logos/          # Logo files in various formats
├── colors/         # Color swatches and palettes
├── fonts/          # Font files and licensing info
└── images/         # Brand imagery and graphics
```

## Quick Reference

### Primary Colors

```
Yellow:  #FFB400 (Primary brand yellow)
Red:     #E1331A (Primary brand red)
Magenta: #E4002A (Accent)
Orange:  #F37920 (Energetic highlights)
```

### Typography Fonts

1. **Gabriel Sans** - BOLD/NORMAL
2. **Neue Montreal** - BOLD
3. **Nourd** - BOLD/NORMAL/THIN
4. **Gordita** - BOLD
5. **Raleway** - THIN

## Logo Usage

- **Light backgrounds**: Use black logo with colored Y
- **Dark backgrounds**: Use white logo with colored Y
- **Icon/Favicon**: Use the bird mark
- **Minimum size**: 24px height for digital applications

## Adding New Assets

When adding new brand assets:
1. Use descriptive file names (e.g., `symmetri-logo-light.svg`)
2. Include multiple formats when possible (SVG, PNG, JPG)
3. Update this README if adding new asset categories
4. Ensure assets follow brand guidelines

## Asset Naming Convention

```
symmetri-[type]-[variant]-[size].[format]

Examples:
- symmetri-logo-light.svg
- symmetri-logo-dark-2x.png
- symmetri-mark-full-color.svg
- symmetri-icon-mono-white-32.png
```
